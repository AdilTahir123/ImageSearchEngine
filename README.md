
# 🖼️ Image Search Engine

A simple image search engine built using HTML, CSS, JavaScript, and the Unsplash API.

## 🚀 Live Demo

[View Live Demo](https://image-search-engine-wfkm.vercel.app/)

## ✨ Features

- 🔍 Search images using keywords
- 🖼️ Display images dynamically
- 📱 Responsive grid layout
- 🎨 Clean and simple UI
- ⚡ Real-time image search using the Unsplash API

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Unsplash API

## 📚 About This Project

I built this project to practice working with APIs and JavaScript.

The application takes a user's search query and fetches relevant images from the Unsplash API, then displays them in a responsive gallery.

## 📁 File Structure

image-search-engine/
├── index.html
├── style.css
├── script.js
└── README.md

## ⚙️ How to Use

1. Get an API key from Unsplash.
2. Add your API key in `script.js`.
3. Open `index.html` in your browser.
4. Enter a keyword such as `nature`, `cars`, or `mountains`.
5. Press Enter or search to view images.

## ⚠️ Note

Do not expose your API key in a public repository. For production applications, use a secure backend or environment variables.
